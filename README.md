# 🃏 Poker Settlement & Stats Discord Bot

บอทจัดการโต๊ะโป๊กเกอร์ สรุปยอดเงิน เคลียร์หนี้อัตโนมัติ (ใครต้องโอนให้ใครด้วยจำนวนครั้งที่น้อยที่สุด) รองรับคนออกกลางคัน สรุปสถิติรายเดือน/รายปี พร้อมระบบ **AI สแกนรูปหน้าจอโต๊ะคิดเงินอัตโนมัติ**, ระบบ **ดึงเพื่อนจาก Voice Call**, ระบบ **🎮 Live Activity โต๊ะเล่นเกมสดผ่านเว็บพร้อม Bot AI** และระบบใหม่ล่าสุด **💸 ทวงหนี้และตรวจสลิปโอนเงินอัตโนมัติด้วย AI สไตล์ขุนทอง (KhunThong Slip Auto-Verify)**

---

## ✨ ฟีเจอร์หลัก (Key Features)

### 1. 💸 ระบบตรวจสลิปโอนเงิน AI & ตัดหนี้อัตโนมัติ สไตล์ขุนทอง (`/poker slip` & Chat Auto-Detect)
- **สแกนและตัดหนี้อัตโนมัติ:** เมื่อจบเกมและมีบิลเรียกเก็บเงิน ผู้เล่นสามารถ **แนบรูปสลิปส่งลงในห้องแชทได้ทันที** (บอทจะตรวจจับรูปสลิปให้อัตโนมัติ) หรือใช้คำสั่ง `/poker slip <image>` หรือกดปุ่ม **[💸 แนบสลิปโอนเงิน]** บนบิล
- **ขับเคลื่อนด้วย Google Gemini AI (3.5 Flash Lite / 3.8 Flash):** อ่านยอดเงิน (Amount), วันและเวลาโอน, ผู้โอน, ผู้รับ (เบอร์พร้อมเพย์/ชื่อบัญชี) และรหัสอ้างอิงธุรกรรม (Transaction Ref)
- **ระบบจับคู่อัจฉริยะ (Smart Matching & Title Stripping):** รองรับการตัดคำนำหน้าชื่อภาษาไทย (`น.ส.`, `นางสาว`, `นาย`, `คุณ`) ช่วยจับคู่ชื่อผู้โอน/ผู้รับในสลิปกับชื่อใน Discord และข้อมูลบัญชีธนาคารได้อย่างแม่นยำ
- **ป้องกันสลิปซ้ำ (Duplicate Ref Check):** ตรวจสอบรหัสธุรกรรมจากธนาคาร ป้องกันการนำสลิปเก่าหรือสลิปเดิมมาส่งซ้ำ
- **อัปเดตสถานะบิลแบบเรียลไทม์:** เปลี่ยนสถานะจาก `[⏳ รอชำระ]` เป็น `[✅ จ่ายแล้ว]` บนบิลหลักในห้องแชททันที พร้อมออกใบเสร็จสรุปยอด
- **ปุ่มป้องกันความผิดพลาด [❌ เงินไม่เข้า (ยกเลิกการชำระ)]:** หากเจ้าหนี้ตรวจสอบแล้วพบว่าเงินไม่เข้าบัญชีจริง สามารถกดปุ่มนี้เพื่อยกเลิกสถานะและดึงยอดหนี้กลับมาทวงใหม่ได้ทันที

### 2. 💵 คำสั่งชำระเงินสด / จ่ายแล้ว (`/poker paid` & `/poker confirm-paid`)
- **รองรับการจ่ายเงินสดและโอนนอกรอบ:** สำหรับคนที่จ่ายเงินสดตรงข้ามโต๊ะ หรือโอนตรงโดยไม่มีสลิป สามารถพิมพ์ `/poker paid` เพื่อบันทึกว่าชำระแล้วได้ทันที
- **เลือกวิธีการชำระได้:** มีตัวเลือก `💵 เงินสด`, `📱 โอนตรงนอกรอบ` หรือ `🤝 เคลียร์ยอดแล้ว`
- **ปุ่ม Interactive Quick Paid:** เมื่อพิมพ์คำสั่ง บอทจะมีปุ่มให้กดยืนยันตัดหนี้ได้ทันทีโดยไม่ต้องจำตัวเลข
- **กดยืนยันผ่านบิล:** เจ้าหนี้สามารถกดปุ่ม **[✅ ได้รับเงินแล้ว (Manual)]** บนบิลสรุปยอด หรือใช้คำสั่ง `/poker confirm-paid` เพื่อยืนยันว่าได้รับเงินจากลูกหนี้แล้ว

### 3. 🔔 ระบบสะกิดทวงเงินสไตล์ขุนทอง (`/poker remind`)
- **แท็กเตือนเพื่อนที่ค้างชำระ:** กดปุ่ม **[🔔 สะกิดทวงเงิน]** บนบิล หรือพิมพ์คำสั่ง `/poker remind`
- **ข้อความทวงเงินแบบสุ่มสุดกวน:** มีมุกทวงหนี้ฮาๆ เปลี่ยนไปเรื่อยๆ พร้อมระบุจำนวนครั้งที่ทวง (`เตือนรอบที่ X`)
- **แนบ QR Code พร้อมยอดเงินใหม่อีกครั้ง:** ช่วยให้เพื่อนที่ยังไม่จ่ายสามารถสแกนโอนเงินได้สะดวกรวดเร็ว

### 4. 🎮 โต๊ะเกมสด Texas Hold'em Live Activity (`/poker play`)
- เปิดโต๊ะเล่นโป๊กเกอร์แบบสดผ่าน Discord Activity หรือเบราว์เซอร์ รองรับได้สูงสุด 9 ที่นั่ง
- **ระบบ Bot AI:** กดปุ่ม **[🤖 เพิ่ม Bot]** เพื่อเติมที่นั่งว่างหรือซ้อมมือคนเดียวได้
- **แอนิเมชันและเอฟเฟกต์เสียง:** มีเสียง Call, Raise, Fold, Check, เสียงชนะ (Win) และเสียงนับถอยหลัง Timer
- **ระบบแจกไพ่รอบต่อไปอัตโนมัติ (Auto-Deal Loop):** หลังจบเกม ระบบจะนับถอยหลัง 3 วินาทีแล้วเริ่มแฮนด์ถัดไปให้อัตโนมัติ
- **ระบบปรับแต่งโต๊ะ (Table Settings):** Host สามารถปรับ Buy-in, Turn Timer และยอด Blinds (SB/BB) ได้แบบเรียลไทม์
- **ปุ่มคิดเงินบนโต๊ะ:** เมื่อเล่นเสร็จ กดปุ่ม "คิดเงิน" ระบบจะสรุปยอดเงิน กำไร/ขาดทุน และส่งบิลเคลียร์หนี้พร้อม QR Code ลง Discord ให้ทันที

### 5. 📸 AI Vision Auto-Cashout (`/poker scan-table`)
- ขับเคลื่อนด้วย **Google Gemini AI** แค่แคปรูปหน้าจอโต๊ะโป๊กเกอร์ตอนจบเกมส่งให้บอท AI จะอ่านชื่อผู้เล่นและจำนวนชิปที่เหลือของทุกคนบนโต๊ะให้อัตโนมัติ
- **สแกนได้ทันทีโดยไม่ต้องเปิดโต๊ะไว้ก่อน:** ไม่จำเป็นต้องพิมพ์ `/poker start` ไว้ล่วงหน้า บอทจะสร้าง Session และดึงรายชื่อจากห้อง Voice Call, สมาชิกในเซิร์ฟเวอร์ หรือชื่อบนรูปภาพมาคิดเงินให้ทันที
- กำหนดค่า Buy-in ต่อคนได้ (ค่าเริ่มต้น 200 บาท)

### 6. 🎙️ Auto Voice Join (`/poker start-voice`)
- ดึงทุกคนที่กำลังนั่งอยู่ในห้อง Voice Call เข้าโต๊ะให้อัตโนมัติทันที ทุกคนไม่ต้องกดปุ่ม Join เอง

### 7. ระบบโต๊ะแบบ Interactive (Embed + Buttons + Modals)
- **Row 1:** `[🟢 เข้าร่วม]`, `[🔄 Rebuy]`, `[➕ เติมชิป (ระบุเอง)]`, `[🏃 ขอออกก่อน]`
- **Row 2:** `[📸 คิดเงินด้วย AI (สแกนรูป)]`, `[🧮 คิดเงิน (ไม่ปิดโต๊ะ)]`, `[🏁 ปิดโต๊ะ / จบเกม]`, `[📊 เช็คสถานะ]`, `[🔄 รีเฟรช]`
- **Row บิลคิดเงิน:** `[💸 แนบสลิปโอนเงิน]`, `[🔔 สะกิดทวงเงิน]`, `[✅ ได้รับเงินแล้ว (Manual)]`, `[✏️ แก้ไขยอดเงิน]`, `[🔄 เริ่มรอบใหม่]`, `[🏆 ดูอันดับ]`

### 8. แก้ปัญหาคนออกกลางคัน (Early Cash-out)
- คนที่ขอตัวไปนอนหรือเลิกก่อน สามารถกดปุ่ม **[🏃 ขอออกก่อน]** หรือพิมพ์ `/poker leave [ชิป]`
- บอทจะแช่แข็งยอดไว้ แล้วนำมาคำนวณเคลียร์หนี้พร้อมกันตอนจบโต๊ะ

### 9. อัลกอริทึมเคลียร์หนี้ (Minimum Cash Flow Algorithm)
- ตรวจสอบยอดเงิน Zero-sum ($\sum \text{Buy-in} = \sum \text{Cash-out}$) ป้องกันชิปตกหล่น
- จับคู่โอนเงินให้เหลือน้อยรอบที่สุด (เช่น B และ C ขาดทุนคนละ 100 ➜ โอนตรงให้ A 200 บาทคนเดียว)

### 10. สร้าง PromptPay & Custom QR Code รับเงิน พร้อมระบบบันทึกชื่อบัญชีธนาคาร (`/profile`)
- **บันทึกชื่อบัญชีธนาคาร (`/profile set-name`):** บันทึกชื่อ-นามสกุลจริง เพื่อให้ระบบ AI สแกนสลิปจับคู่ผู้รับเงินได้อย่างถูกต้อง 100%
- **เบอร์พร้อมเพย์ (`/profile set-promptpay`):** เจน QR Code ยอดเงินอัตโนมัติเมื่อชนะ
- **รูปภาพ QR Code ส่วนตัว (`/profile set-qr`):** อัปโหลดภาพ QR ธนาคารส่วนตัวเพื่อให้เพื่อนสแกนได้ทันที

### 11. ระบบสถิติและทำเนียบเซียน (Stats & Leaderboard)
- สรุปสถิติส่วนบุคคล (Win Rate %, กำไรสะสม, Best Win/Loss)
- สรุปผลประจำเดือน และประจำปี
- แจกฉายา **🦈 The Shark** (คนกวาดกำไรสูงสุด) และ **🐟 The Sponsor** (ผู้สนับสนุนหลัก เสียเยอะสุด)

### 12. 📝 ระบบคิดเงินแบบพิมพ์เอง & แก้ไขได้ตลอด (Manual Record & Edit)
- พิมพ์บันทึกยอดเงินง่ายๆ เช่น `@Ton 350, @Nadear 50` หรือแยกรายคน `@Nadear 50 buyin:400`
- บันทึกลงฐานข้อมูลและอัปเดตตาราง Leaderboard ทันที
- กดปุ่ม **[✏️ แก้ไขยอดเงิน (Edit)]** บนสรุปผล หรือพิมพ์ `/poker edit` เพื่อแก้ตัวเลขและคำนวณใหม่ได้ตลอดเวลา

### 13. 🧹 ระบบเคลียร์ห้องแชท (`/clear`) & ล้างข้อมูลระบบ (`/poker reset-all`)
- ลบข้อความและสลิปในห้องแชทครั้งละ 1 - 100 ข้อความด้วย `/clear`
- รีเซ็ตประวัติโต๊ะและหนี้ทั้งหมดเมื่อต้องการเริ่มใหม่ด้วย `/poker reset-all confirm:True`

## 🚀 วิธีติดตั้งและเปิดใช้งาน (Setup Guide)

### 1. การตั้งค่าตัวแปรในไฟล์ `.env`
คัดลอกไฟล์ `.env.example` เป็น `.env`:
```bash

```
ใส่ค่าในไฟล์ `.env`:
```env

PORT=8000

SUPABASE_URL=URL ของ Supabase Project (แนะนำสำหรับ Cloud Hosting)
SUPABASE_KEY=Anon/Service Role Key ของ Supabase
```

## 🌐 คู่มือการเปิดบอท 24 ชั่วโมงบน Render Free Tier & ป้องกันเซิร์ฟเวอร์หลับ

### 💡 ทำไมบอทบน Render แผนฟรีถึงหยุดทำงาน (Spin down after 15 mins)?
- **กลไกของ Render Free Tier:** Render Web Service แผนฟรีจะหยุดทำงานชั่วคราว (Spin down เข้า Sleep Mode) โดยอัตโนมัติ หากไม่มี **Inbound HTTP Request** จากภายนอกเข้ามานานเกิน **15 นาที** เพื่อประหยัดทรัพยากร
- **โควตาฟรี 750 ชั่วโมง/เดือน:** Render ให้โควตาการรัน Free Instance สูงถึง **750 ชั่วโมงต่อเดือนฟรี** ซึ่งเพียงพอสำหรับการรันบอทตลอด 24 ชั่วโมงทั้งเดือน (31 วัน × 24 ชม. = 744 ชั่วโมง)

### 🛠️ วิธีทำให้บอทออนไลน์ตลอด 24 ชั่วโมง ไม่มีหลับ

โปรเจกต์นี้รองรับระบบ Keep-Alive 2 ชั้นเพื่อให้บอทออนไลน์ถาวร:

#### ชั้นที่ 1: ระบบ Auto Keep-Alive ในตัวบอท
เมื่อรันบน Render บอทจะตรวจจับตัวแปรระบบ `RENDER_EXTERNAL_URL` (หรือ `APP_URL`) โดยอัตโนมัติ และจะส่ง Ping ไปยัง Health Check Endpoint ทุกๆ **8 นาที** เพื่อป้องกันไม่ให้อินสแตนซ์หยุดทำงาน

#### ชั้นที่ 2: ตั้งค่า UptimeRobot ให้ยิง Ping จากภายนอก (แนะนำ 100%)
เนื่องจากบางครั้ง HTTP Request ภายในเครื่องอาจไม่นับเป็น Inbound Request จากภายนอก การใช้ **[UptimeRobot](https://uptimerobot.com/)** เป็นวิธีที่แน่นอนและนิยมที่สุดในหมู่ Discord Bot Developer:

1. สมัครใช้งาน [UptimeRobot.com](https://uptimerobot.com/) (ฟรีตลอดชีพ ไม่มีค่าใช้จ่าย)
2. กดปุ่ม **+ Add New Monitor**
3. ตั้งค่า Monitor:
   - **Monitor Type:** `HTTP(s)`
   - **Friendly Name:** `Poker Bot Render`
   - **URL (or IP):** ใส่ Web Service URL ของคุณจาก Render (เช่น `https://poker-bot.onrender.com/`)
   - **Monitoring Interval:** ทุกๆ `5 minutes`
4. กด **Create Monitor**
> [!TIP]
> แผนฟรีของ UptimeRobot รองรับการมอนิเตอร์สูงสุดถึง **50 Monitors** เช็คทุก 5 นาที และไม่มีค่าใช้จ่ายแอบแฝง เพียงตั้งค่านี้ บอทของคุณจะไม่มีวันหลับตลอด 24 ชม. 365 วัน!

## ⚡ ฐานข้อมูลถาวร Supabase (Permanent Cloud Database)
เมื่อรันบน Render.com แผนฟรี ข้อมูลไฟล์ในเครื่องจะถูกรีเซ็ตเมื่อบอทรีสตาร์ท คุณสามารถเชื่อมต่อ **Supabase (ฟรีตลอดชีพ 500 MB)** เพื่อเก็บข้อมูลถาวรได้ใน 3 นาที:

1. เข้าเว็บ [Supabase.com](https://supabase.com/) ➔ กด **New Project** ตั้งชื่อโปรเจกต์
2. ไปที่แท็บ **SQL Editor** ด้านซ้าย ➔ กด **New query** ➔ ก๊อปปี้โค้ดจากไฟล์ [`supabase-schema.sql`](supabase-schema.sql) ทั้งหมดไปวาง ➔ กด **Run** (สร้างตารางเสร็จทันที)
3. ไปที่ **Project Settings** ➔ **API** ➔ ก๊อปปี้:
   - **Project URL** ➔ ใส่ใน `SUPABASE_URL`
   - **anon public** หรือ **service_role** ➔ ใส่ใน `SUPABASE_KEY`
4. นำทั้ง 2 ค่าไปใส่ใน Environment Variables บน Render หรือไฟล์ `.env` ในเครื่อง
5. เมื่อบอทเริ่มทำงาน จะมีข้อความแจ้งเตือนว่าเชื่อมต่อ Supabase สำเร็จ และจะดึงข้อมูลเดิมจากไฟล์ JSON ขึ้น Supabase ให้อัตโนมัติ!

## 🗄️ โครงสร้างฐานข้อมูล (Database Architecture)
บอทรองรับระบบ Hybrid Database อัตโนมัติ:
- **เมื่อตั้งค่า Supabase (`SUPABASE_URL` + `SUPABASE_KEY`)**: เก็บข้อมูลบน PostgreSQL Cloud ถาวร 100% เปิดดู/แก้ไขผ่านหน้าเว็บ Supabase ได้
- **เมื่อไม่ได้ตั้งค่า Supabase**: บอทจะบันทึกลงไฟล์ `data/poker-data.json` ในเครื่องโดยอัตโนมัติ (Zero-config สำหรับเทสในเครื่อง)
