# 🃏 Poker Settlement & Stats Discord Bot

บอทจัดการโต๊ะโป๊กเกอร์ สรุปยอดเงิน เคลียร์หนี้อัตโนมัติ (ใครต้องโอนให้ใครด้วยจำนวนครั้งที่น้อยที่สุด) รองรับคนออกกลางคัน สรุปสถิติรายเดือน/รายปี พร้อมระบบ **AI สแกนรูปภาพหน้าจอโต๊ะคิดเงินอัตโนมัติ (สแกนได้ทันทีโดยไม่ต้องเปิดโต๊ะล่วงหน้า)**, ระบบ **ดึงเพื่อนจากห้อง Voice Call เข้าโต๊ะทันที** และระบบ **🎮 Live Activity / โต๊ะเล่นเกมสดผ่านเว็บพร้อมระบบ Bot AI**

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. **🎮 โต๊ะเกมสด Texas Hold'em Live Activity (`/poker play`)**:
   - เปิดโต๊ะเล่นโป๊กเกอร์แบบสดผ่าน Discord Activity หรือเบราว์เซอร์ รองรับได้สูงสุด 9 ที่นั่ง
   - **ระบบ Bot AI:** สามารถกดปุ่ม **[🤖 เพิ่ม Bot]** เพื่อเติมที่นั่งว่างหรือซ้อมมือคนเดียวได้
   - **แอนิเมชันและเอฟเฟกต์เสียง:** มีเสียง Call, Raise, Fold, Check, เสียงชนะ (Win) และเสียงนับถอยหลัง Timer
   - **ระบบแจกไพ่รอบต่อไปอัตโนมัติ (Auto-Deal Loop):** หลัง Showdown/Fold จบเกม ระบบจะนับถอยหลัง 3 วินาทีแล้วแจกไพ่แฮนด์ถัดไปให้อัตโนมัติ พร้อมปุ่มเริ่มมือถัดไปด้วยตัวเอง
   - **ระบบปรับแต่งโต๊ะ (Table Settings):** Host สามารถตั้งค่ายอด Buy-in (ค่าเริ่มต้น 200฿), ปรับเวลานับถอยหลังต่อเทิร์น (Turn Timer) และปรับยอด Blinds (Small Blind / Big Blind) ได้แบบเรียลไทม์
   - **ปุ่มคิดเงินบนโต๊ะ:** เมื่อเล่นเสร็จ กดปุ่ม "คิดเงิน" ระบบจะสรุปยอดเงิน กำไร/ขาดทุน และส่งบิลเคลียร์หนี้พร้อม QR Code ลงห้อง Discord ให้ทันที

2. **📸 AI Vision Auto-Cashout (`/poker scan-table`)**:
   - ขับเคลื่อนด้วย **Google Gemini AI** แค่แคปรูปหน้าจอโต๊ะโป๊กเกอร์ตอนจบเกมส่งให้บอท AI จะอ่านชื่อผู้เล่นและจำนวนชิปที่เหลือของทุกคนบนโต๊ะให้อัตโนมัติ
   - **สแกนได้ทันทีโดยไม่ต้องเปิดโต๊ะไว้ก่อน:** ไม่จำเป็นต้องพิมพ์ `/poker start` ไว้ล่วงหน้า บอทจะสร้าง Session และดึงรายชื่อจากห้อง Voice Call, สมาชิกในเซิร์ฟเวอร์ หรือชื่อบนรูปภาพมาคิดเงินให้ทันที
   - **กำหนดตัวเลือก Buy-in ได้:** มีตัวเลือก `buyin` (ค่าเริ่มต้น 200 บาท)

3. **🎙️ Auto Voice Join (`/poker start-voice`)**:
   - ดึงทุกคนที่กำลังนั่งอยู่ในห้อง Voice Call เข้าโต๊ะให้อัตโนมัติทันที ทุกคนไม่ต้องกดปุ่ม Join เอง (ค่าเริ่มต้น 200 บาท)

4. **ระบบโต๊ะแบบ Interactive (Embed + Buttons + Modals)**:
   - **Row 1:** `[🟢 เข้าร่วม]`, `[🔄 Rebuy]`, `[➕ เติมชิป (ระบุเอง)]`, `[🏃 ขอออกก่อน]`
   - **Row 2:** `[📸 คิดเงินด้วย AI (สแกนรูป)]`, `[🧮 คิดเงิน (ไม่ปิดโต๊ะ)]`, `[🏁 ปิดโต๊ะ / จบเกม]`, `[📊 เช็คสถานะ]`, `[🔄 รีเฟรช]`
   - ปุ่ม **📸 คิดเงินด้วย AI (สแกนรูป)**: กดปุ่มแล้วเลือกโหมด (🧮 สแกนดูยอดไม่ปิดโต๊ะ หรือ 🏁 สแกนคิดเงินปิดโต๊ะ) แล้วแนบส่งรูปภาพในห้องแชทได้ทันที
   - ปุ่ม **📊 เช็คสถานะ**: ดูสถานะโต๊ะล่าสุด ยอดกองกลาง รายชื่อผู้เล่น และยอด Buy-in ส่วนตัวได้ทันที

5. **แก้ปัญหาคนออกกลางคัน (Early Cash-out)**:
   - คนที่ขอตัวไปนอนหรือเลิกก่อน สามารถกดปุ่ม **[🏃 ขอออกก่อน]** หรือพิมพ์ `/poker leave [ชิป]`
   - บอทจะแช่แข็งยอดไว้ แล้วนำมาคำนวณเคลียร์หนี้พร้อมกันตอนจบโต๊ะ

6. **อัลกอริทึมเคลียร์หนี้ (Minimum Cash Flow Algorithm)**:
   - ตรวจสอบยอดเงิน Zero-sum ($\sum \text{Buy-in} = \sum \text{Cash-out}$) ป้องกันชิปตกหล่น
   - จับคู่โอนเงินให้เหลือน้อยรอบที่สุด (เช่น B และ C ขาดทุนคนละ 100 ➜ โอนตรงให้ A 200 บาทคนเดียว)

7. **สร้าง PromptPay & Custom QR Code รับเงินอัตโนมัติ**:
   - รองรับทั้งการบันทึกเบอร์พร้อมเพย์ (สร้าง QR ยอดเงินอัตโนมัติ) และการอัปโหลดรูป QR Code ธนาคารส่วนตัว
   - บอทจะแนบรูป QR Code ของผู้ชนะสูงสุดในโต๊ะให้สแกนจ่ายเงินได้ทันทีใน Discord

8. **ระบบสถิติและทำเนียบเซียน (Stats & Leaderboard)**:
   - สรุปสถิติส่วนบุคคล (Win Rate %, กำไรสะสม, Best Win/Loss)
   - สรุปผลประจำเดือน และประจำปี
   - แจกฉายา **🦈 The Shark** (คนกวาดกำไรสูงสุด) และ **🐟 The Sponsor** (ผู้สนับสนุนหลัก เสียเยอะสุด)

9. **🧹 ระบบเคลียร์ห้องแชท (`/clear`)**:
   - ลบข้อความทดสอบและสลิปในห้องแชทได้ครั้งละ 1 - 100 ข้อความอย่างรวดเร็ว

## 🚀 วิธีติดตั้งและเปิดใช้งาน (Setup Guide)

### 1. การตั้งค่าตัวแปรในไฟล์ `.env`
คัดลอกไฟล์ `.env.example` เป็น `.env`:
```bash
cp .env.example .env
```
ใส่ค่าในไฟล์ `.env`:
```env
DISCORD_TOKEN=โทเคนบอทของคุณ (ได้จาก Discord Developer Portal > Bot)
CLIENT_ID=เลข_Application_ID (ได้จาก Discord Developer Portal > General Information)
GUILD_ID=เลข_Server_ID (คลิกขวาที่ชื่อ Discord Server > Copy Server ID)
GEMINI_API_KEY=รหัสคีย์_Gemini_AI (รับฟรีได้ที่ https://aistudio.google.com/apikey)
PORT=8000
APP_URL=https://your-domain.onrender.com (หรือ http://localhost:8000 เมื่อรันในเครื่อง)
```

### 2. ติดตั้ง Dependencies และลงทะเบียนคำสั่ง Slash Command
```bash
npm install
npm run register
```

### 3. รัน Unit Tests (ทดสอบความถูกต้องของระบบ)
```bash
npm run build && npx tsx --test tests/**/*.test.ts
```

## 🌐 ตัวเลือกการเปิดบอท (Deployment)

### ตัวเลือกที่ 1: รันบน Cloud ฟรี 24 ชม. (Render.com)
บอทจะออนไลน์ตลอด 24 ชั่วโมงแม้คุณจะปิดคอมพิวเตอร์:
1. นำโค้ดขึ้น GitHub ของคุณ
2. เข้าเว็บ [Render.com](https://render.com/) ➔ กด **New Web Service** ➔ เลือก Repo `Poker-bot`
3. ตั้งค่า:
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
   - **Instance Type:** `Free`
4. ใส่ตัวแปรในแท็บ **Environment Variables**:
   - `DISCORD_TOKEN`
   - `CLIENT_ID`
   - `GUILD_ID`
   - `GEMINI_API_KEY` (สำหรับระบบสแกนรูป)
   - `APP_URL` (URL ของ Web Service บน Render เช่น `https://poker-bot.onrender.com`)
   - `SUPABASE_URL` *(แนะนำ: เพื่อเก็บข้อมูลถาวร 100%)*
   - `SUPABASE_KEY` *(แนะนำ: เพื่อเก็บข้อมูลถาวร 100%)*
5. กด Deploy เสร็จสิ้น!

## ⚡ ฐานข้อมูลถาวร Supabase (Permanent Cloud Database)
เมื่อรันบน Render.com แผนฟรี หากไม่มี Database ภายนอก ข้อมูลไฟล์ในเครื่องจะถูกล้างเมื่อบอทรีสตาร์ท คุณสามารถเชื่อมต่อ **Supabase (ฟรีตลอดชีพ 500 MB)** เพื่อเก็บข้อมูลถาวรได้ใน 3 นาที:

1. เข้าเว็บ [Supabase.com](https://supabase.com/) ➔ กด **New Project** ตั้งชื่อโปรเจกต์
2. ไปที่แท็บ **SQL Editor** ด้านซ้าย ➔ กด **New query** ➔ ก๊อปปี้โค้ดจากไฟล์ [`supabase-schema.sql`](supabase-schema.sql) ทั้งหมดไปวาง ➔ กด **Run** (สร้างตารางเสร็จทันที)
3. ไปที่ **Project Settings** ➔ **API** ➔ ก๊อปปี้:
   - **Project URL** ➔ ใส่ใน `SUPABASE_URL`
   - **anon public** หรือ **service_role** ➔ ใส่ใน `SUPABASE_KEY`
4. นำทั้ง 2 ค่าไปใส่ใน Environment Variables บน Render หรือไฟล์ `.env` ในเครื่อง
5. เมื่อบอทเริ่มทำงาน จะมีข้อความแจ้งเตือนว่าเชื่อมต่อ Supabase สำเร็จ และจะดึงข้อมูลเดิมจากไฟล์ JSON ขึ้น Supabase ให้อัตโนมัติ!

## 🗄️ โครงสร้างฐานข้อมูล (Database Architecture)
บอทรองรับระบบ Hybrid Database อัตโนมัติ:
- **เมื่อตั้งค่า Supabase (`SUPABASE_URL` + `SUPABASE_KEY`)**: เก็บข้อมูลบน PostgreSQL Cloud ถาวร 100% เปิดดู/แก้ไขผ่านหน้าเว็บ Supabase ได้
- **เมื่อไม่ได้ตั้งค่า Supabase**: บอทจะบันทึกลงไฟล์ `data/poker-data.json` ในเครื่องโดยอัตโนมัติ (Zero-config สำหรับเทสในเครื่อง)
